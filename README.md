# 🛒 Superstore Sales Analysis Using MySQL

## 📌 Project Overview

This project analyzes Superstore sales data using MySQL to
identify sales trends, customer behavior, product performance,
profitability, and regional business performance.

The goal is to use SQL to answer practical business questions
and generate insights that can support better decision-making.

---

## 🛠️ Tools & Technologies

- MySQL
- SQL
- MySQL Workbench
- CSV Dataset
- Data Analysis

---

## 📊 Business Questions

This project will answer questions such as:

1. What are the total sales and total profit?
2. Which products generate the highest sales?
3. Which products generate the highest profit?
4. Which categories perform best?
5. Which regions generate the most revenue?
6. Who are the most valuable customers?
7. What are the monthly sales trends?
8. Which products have high sales but low profit?
9. Which regions have the highest profit margins?
10. What business insights can be derived from the data?
